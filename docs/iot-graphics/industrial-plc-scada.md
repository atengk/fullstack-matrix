# 工业物联网 PLC 通信协议与 SCADA 智能数采 (Industrial IoT & PLC)

## 1. 模式 A：工业现场总线与主流 PLC 硬件直接通信驱动 (Apache PLC4X + Libplctag + open62541)

### 1.1 核心技术栈清单与职责说明
| 架构层级 | 推荐选型 | 职责与功能定位说明 |
| :--- | :--- | :--- |
| **多厂商统一 PLC 通信协议栈** | `Apache PLC4X` (支持 Java / Go / C++) | 顶级开源通用工业协议框架，提供统一的读写 API 屏蔽底层协议差异，无需安装各工控厂商昂贵的闭源专有驱动 |
| **西门子工业级专用极速驱动** | `Snap7` (基于 C/C++ 深度优化) | 专为西门子 S7-200 / 300 / 400 / 1200 / 1500 系列 PLC 打造的高性能通信库，微秒级直接读写 PLC DB 块、输入输出与标记位 |
| **罗克韦尔专用高性能驱动** | `libplctag` (基于 C 语言编写) | 工业级开源通信库，原生支持 Rockwell/Allen-Bradley (ControlLogix, CompactLogix) 的 EtherNet/IP 与 CIP 协议原生标签读写 |
| **下一代工业互联通信标准** | `OPC UA (open62541 / Eclipse Milo)` | 跨平台、面向对象的下一代工业物联网事实标准，具备严格 TLS 加密与 X.509 证书鉴权，原生支持复杂工业设备信息模型定义 |
| **经典工业现场总线轮询底盘** | `Modbus (TCP / RTU)` | 工业自动化最广泛的基础总线协议，纳管老旧温度仪表、变频器、智能电表与继电器模块的 RS-485 串口/以太网高频轮询 |
| **寄存器点位动态映射与规整** | 点位表驱动配置引擎 (Point Registry) | 将晦涩物理地址（如 `DB1.DBD10`）动态转译为业务语义 JSON 字段，并自动完成大端/小端字节序（Endianness）与高低字倒序转换 |

### 1.2 核心选型考量与技术优势
* **终结厂商闭源上位机软件高昂授权垄断**：
  * 传统工业现场被西门子 WinCC、罗克韦尔 FactoryTalk 等巨头垄断，单套软件授权动辄数万至数十万元，且接口封闭、无法与现代互联网微服务直接对接；
  * 基于 Apache PLC4X 与 Snap7 打造自主可控的数采服务，通过以太网直连车间 PLC，彻底打破厂商技术封锁，实现工业数据的 100% 自主掌控；
* **连续点位自动合并与 PLC CPU 降载优化**：
  * 经验不足的数采系统逐个点位发起网络请求，会导致 PLC 工业芯片通信网络过载甚至引起生产死机事故；
  * 驱动层内置连续地址合并打包算法：系统自动分析点位表，将离散的 100 个点位合并为 1~2 次连续字节块请求（Block Read），将网络往返延迟降至最低，数据轮询频次轻松突破 50Hz~100Hz；
* **严苛的工控数据字节序防御 (Endianness Safety)**：
  * 工业 PLC 硬件芯片架构各异，广泛存在大端（Big-Endian）、小端（Little-Endian）以及双字高低字颠倒（CDAB/BADC）格式；
  * 协议栈在底层建立强类型映射，对浮点数（IEEE 754）、双精度、整型数据实施自动化字节对齐校验，杜绝因高低位倒置导致把“25.3℃”解析成“负几万度”的致命工控乌龙。

### 1.3 适用业务场景
* 汽车整车制造自动化冲压、焊装、涂装车间 PLC 点位毫秒级状态监控与质量防错追溯；
* 3C 电子高速自动化组装流水线、数控机床（CNC）主轴温度与伺服电机振动数据采集；
* 锂电池电芯生产化成与分容车间高频充放电数据记录与火灾预警联动。

## 2. 模式 B：工业边缘轻量网关流转与低代码 SCADA 组态中枢 (EMQX Neuron + Node-RED + FUXA)

### 2.1 核心技术栈清单与职责说明
| 架构层级 | 推荐选型 | 职责与功能定位说明 |
| :--- | :--- | :--- |
| **工业协议轻量边缘数采网关** | `EMQX Neuron (NeuronEX)` (纯 C 语言编写) | 新一代超轻量工业边缘网关，单机仅占用几兆内存，纳管数万工业点位，将各类工业协议毫秒级转换为标准 MQTT 统一输出 |
| **低代码工业数据流转与清洗** | `Node-RED` (基于 Flow 的可视化编排) | 工业物联网流程粘合利器，数分钟内通过拖拽节点打通 PLC 数据提取、死区滤波、阈值告警判断与上云转发 |
| **纯 Web 现代化轻量 SCADA 组态**| `FUXA` (开源 Web 组态监控系统) | 现代化纯浏览器端 SCADA/HMI 软件，支持在网页中自由拖拽储罐、阀门、管道图元并动态绑定实时数据与工艺报警 |
| **边缘离线断点续传与防抖中枢** | `SQLite / DuckDB` + 环形内存队列 | 专为车间边缘弱网设计，网络中断时在工控机本地持久化带时间戳的数采数据，网络重连后无损顺序补报，确保历史数据零丢点 |
| **数据降噪与死区压缩引擎** | `Deadband 变化率过滤算法` | 边缘端动态过滤无效微小杂波（如压力在 0.5% 内波动不上传），极大节约 70% 以上工业网络传输带宽与云端存储开销 |

### 2.2 核心选型考量与技术优势
* **超轻量纯 C 架构（工控硬件即插即用）**：
  * Neuron 专为边缘计算盒（如研华、西门子 IOT2050、国产 ARM 工控机）打造，内存开销 < 50MB，CPU 占用率 < 3%；
  * 工程师无需编写代码，通过浏览器 Web 页面即可图形化配置设备 IP、端口与点位表，几分钟即可完成数十台 PLC 的统一数据归一化；
* **南向工控协议与北向云端架构彻底解耦**：
  * Neuron 作为工业协议收敛网关，南向接管 Modbus、S7、EtherNet/IP、OPC UA，北向统一转换为标准 MQTT 格式推流至第 18/20 节消息中枢，云端开发者无需理解复杂的工控协议，直接消费统一规范的 JSON 数据；
* **终结传统 Windows 宿主机安装包（纯 Web 组态 FUXA）**：
  * 传统组态软件必须在工控现场安装繁重的 Windows 客户端；
  * FUXA 支持在任何平板电脑、大屏、手机浏览器上无插件运行；提供水流流动、电机旋转、温度警报等丰富工业动态图元，车间班组长在平板上即可直观监视产线运行工况。

### 2.3 适用业务场景
* 离散制造中小型工厂低成本数字化快速升级、产线看板现场快速上线；
* 环保水处理自动化控制站房、集中式光伏电站与风电机组远程无人值守监控；
* 自动化设备整机制造厂商（OEM）出厂随机配套的嵌入式触控监视一体化界面。

## 3. 双模式选型决策对比与建议

| 评估维度 | 模式 A：工业现场总线直连通信驱动 (PLC4X / Snap7) | 模式 B：边缘轻量网关与 Web SCADA 组态 (Neuron + FUXA) |
| :--- | :--- | :--- |
| **技术实现形态** | 纯代码级底层通信库（Java/Go/C++ 原生嵌入服务） | 开箱即用型软件网关 + 纯 Web 拖拽式组态控制系统 |
| **主导技术组件** | `Apache PLC4X` + `Snap7` + `libplctag` + `open62541` | `EMQX Neuron` + `Node-RED` + `FUXA` + 本地断点存储 |
| **数据采样频率** | 极高（10ms ~ 50ms 级别，支持高频高速工艺控制） | 中高（100ms ~ 1000ms 级别，聚焦业务监测与大屏展示） |
| **开发维护心智** | 需熟悉物理内存地址分配、寄存器偏移量与高低字对齐 | 零代码/低代码配置为主，开箱通过浏览器 Web 界面即开即用 |
| **系统架构定位** | 专职核心高精度数采、高速质检采样与 PLC 双向写控制 | 专职边缘协议转换分流、车间就地组态看板呈现与离线暂存 |
| **推荐适用团队** | 专职工业软件研发工程师、工控物联网核心研发部 | 现场实施运维工程师、工厂自动化工程师、中小型集成商 |
