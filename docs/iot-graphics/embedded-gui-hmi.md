# 嵌入式微型屏 GUI 与工业触控 HMI (Embedded GUI & HMI)

## 1. 模式 A：微控制器与极轻量嵌入式屏幕标准开发 (LVGL 9.x + SquareLine Studio + C/C++)

### 1.1 核心技术栈清单与职责说明
| 架构层级 | 推荐选型 | 职责与功能定位说明 |
| :--- | :--- | :--- |
| **嵌入式图形库绝对事实标准** | `LVGL 9.x (Light and Versatile Graphics Library)` | 纯 C 语言编写的高性能极轻量跨平台 GUI 库，内存仅需 64KB RAM、几百 KB Flash，提供平滑圆角、抗锯齿、阴影与丰富现代动效 |
| **官方拖拽式可视化 UI 设计器**| `SquareLine Studio` (LVGL 官方桌面工具) | 官方可视化拖拽编辑器，支持所见即所得设计界面、属性事件绑定、页面流转预览，并一键导出高质量无冗余的纯 C 驱动源码 |
| **硬件图形加速与双缓冲驱动** | `DMA2D (STM32 Chrom-ART)` / `ESP32 LCD 硬件加速` | 结合 DMA 异步内存位块传输与 Framebuffer 脏矩形局部双缓冲技术，实现单片机微秒级渲染且彻底消除屏幕撕裂 |
| **极小存储中文字体裁剪引擎** | `LVGL Font Converter` (离线字体裁剪器) | 离线提取高频中文 3500 字，生成 2-bit/4-bit 灰度抗锯齿位图字模，将数万汉字矢量字库由数十 MB 极致压缩至几百 KB |
| **多模态外设与物理输入适配** | `Capacitive Touch (I2C)` + `Rotary Encoder 旋钮` | 原生抽象输入设备驱动，全面兼容多点电容触控屏、机械旋转编码器（带按压菜单聚焦）、实体按键与遥控器焦点切换 |

### 1.2 核心选型考量与技术优势
* **单片机微型屏领域绝对统治地位（以极小资源呈现智能手机级动效）**：
  * 在 ESP32-S3、STM32 等没有 MMU、内存仅有数百 KB 至几 MB 的微控制器上，Linux、Android 或 Electron 根本无法启动；
  * LVGL 专为此类极端物理受限芯片而生，凭借精湛的“脏矩形局部重绘（Dirty Rectangle Invalidation）”算法，仅重绘发生变化的局部像素点，以极低 CPU 负载实现流畅的列表滚动、卡片滑动与仪表盘指针旋转；
* **SquareLine Studio 彻底告别“手工算像素坐标调 UI”的时代**：
  * 传统嵌入式单片机 UI 开发完全依赖工程师用 C 语言手写 `x/y` 坐标与颜色值，耗时费力且难以维护；
  * SquareLine Studio 带来现代化可视化拖拽体验，UI 设计师与嵌入式工程师无缝协同，动效时间线与样式即时渲染，一键导出模块化 C 代码，开发效率提升 80% 以上；
* **硬件 DMA 异步搬运彻底释放单片机算力**：
  * 结合芯片硬件 DMA2D 控制器，图像数据在内存缓冲区合成完毕后，由硬件自动搬运到 LCD 屏幕控制芯片，整个刷新过程完全不占用单片机 CPU，CPU 可专心处理传感器数采与 Wi-Fi/蓝牙网络通信；
* **中文极简点阵化无感显示**：
  * 针对中文字符集庞大、单片机 Flash 存储受限的痛点，通过官方离线字库裁剪器，精准只将界面用到的汉字打包为紧凑位图字模，彻底杜绝单片机存储爆满风险。

### 1.3 适用业务场景
* 智能家居 86 型墙壁中控触控屏、智能温控器、带屏带旋钮空调面板；
* 工业手持红外测温仪、便携式气体检测仪、电力智能采集表头微型液晶屏；
* 消费级智能穿戴设备（儿童电话手表、运动手环、桌面高颜值小电视/天气副屏）。

## 2. 模式 B：次时代跨平台现代化轻量 GUI 框架 (Slint + Rust / C++ / Linux 平台)

### 2.1 核心技术栈清单与职责说明
| 架构层级 | 推荐选型 | 职责与功能定位说明 |
| :--- | :--- | :--- |
| **次时代轻量声明式 GUI 框架** | `Slint 1.8+` (原 Qt 核心架构师团队出品) | 基于 Rust 编写的现代化声明式 GUI 引擎，支持 `.slint` 声明式布局语法，体积小巧（内存仅需几 MB），原生支持 Linux、MCU 与桌面全平台 |
| **强类型安全的业务逻辑绑定** | `Rust` 【主选】/ `现代 C++ (C++20)` 【工控主流】 | 界面表现层与业务逻辑层完全解耦，所有属性在编译期由强类型编译器严格检查，彻底消除运行时类型转换崩溃 |
| **自适应图形渲染管线分流** | `FemtoVG (OpenGL ES)` / `Software (纯 CPU 软光栅化)` | 在带 GPU 的高端 ARM Linux 核心板上启用 OpenGL 硬件加速；在无 GPU 的低配工控屏上无缝退化为纯 CPU 极速软渲染 |
| **现代化毫秒级热预览开发环境** | `Slint Live-Preview (VS Code 官方扩展)` | 代码编写与界面调试毫秒级双向热重载，无需等待漫长的交叉编译与板载烧录，大幅提升嵌入式 Linux 交互研发体验 |

### 2.2 核心选型考量与技术优势
* **终结嵌入式 Qt 庞大臃肿与高风险商业授权陷阱**：
  * 传统工控触控屏普遍使用 Qt，但 Qt 动态链接库体积动辄高达 50~100MB，且商业授权极为昂贵复杂，稍有不慎即面临严厉的侵权法律诉讼；
  * Slint 采用商业友好的开源双许可协议，基于 Rust 编写，编译产物为极小、独立的单二进制文件，常驻内存仅需 5~15MB，启动耗时在 100ms 以内；
* **现代化声明式语法与编译期类型安全 (Declarative DSL)**：
  * 具备类似 QML 与 Flutter 的现代化声明式描述语法，代码极其干净直观；但与 QML 运行时解释执行容易出现拼写错误闪退不同，Slint 界面描述语言在编译阶段直接被 Rust 编译器转换为底层高优原生代码，代码安全级别无与伦比；
* **跨平台同构复用与高帧率视觉质感**：
  * 同一套 `.slint` 界面设计资产，不仅可以运行在嵌入式 Linux 工控屏上，还可无缝编译运行在 Windows/macOS 桌面端以及 WebAssembly 浏览器视口中，极大保护企业资产复用性。

### 2.3 适用业务场景
* 工业自动化触控屏（HMI）、数控机床与激光切割设备工控机一体化操作面板；
* 新能源汽车智能充电桩户外交互大屏、智慧加油机触控交互终端；
* 医疗设备台式监护仪、智能厨电（带大屏智能油烟机、微波蒸烤箱）交互控制系统。

## 3. 双模式选型决策对比与建议

| 评估维度 | 模式 A：单片机极轻量图形开发 (LVGL + SquareLine) | 模式 B：次时代跨平台轻量 GUI (Slint + Rust/C++) |
| :--- | :--- | :--- |
| **典型主控硬件平台** | 微控制器 MCU（如 ESP32、STM32、树莓派 RP2040） | 嵌入式 Linux 工控机（全志、瑞芯微 RK3568、NXP i.MX） |
| **硬件内存与存储资源**| RAM: 64KB ~ 8MB，Flash: 几百 KB ~ 16MB | RAM: 32MB ~ 512MB+，ROM/eMMC: 128MB+ |
| **主导开发语言体系** | 纯 C 语言（C99/C11）+ 裸机/FreeRTOS/RT-Thread | 声明式 DSL (`.slint`) + `Rust` / `现代 C++` + Linux |
| **UI 界面设计工具** | `SquareLine Studio` (官方可视化拖拽，直接出 C 代码) | `Slint Live-Preview` (声明式代码编写与实时热重载) |
| **渲染加速支撑** | 依托芯片 DMA2D、硬件位块传输与双缓冲脏矩形刷新 | 依托 OpenGL ES 硬件加速或极高优纯 CPU 软光栅化渲染 |
| **生态成熟度与普及** | 嵌入式单片机绝对霸主，中文资料与硬件驱动极为丰富 | 新兴高性能工业级先锋框架，代码架构现代优雅且内存绝对安全 |
| **推荐适用场景** | 86 中控面板、手持仪器、小家电微型屏、低功耗穿戴设备 | 工业级带屏 HMI、充电桩户外大屏、医疗台式设备操作屏 |
